# One Word From Grandma

Entry for the make.fun bounty "One Word From Grandma".

The program writes ONE WORD — the single word Grandma would text
about AI — to `entry.txt`. A real word, a family in-joke, a typo she
would actually make, or text-speak. The judge picks the funnier,
more grandma-like word.

Our word: **whatchamacallit** — the classic Grandma catch-all for
anything she can't name, now applied to AI.
